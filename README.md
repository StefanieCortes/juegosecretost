# 🎮 Juego Secreto

Proyecto desarrollado como práctica del curso de lógica de programación de **Alura Latam** y **Oracle Next Education (ONE)**.

El juego consiste en adivinar un número secreto generado aleatoriamente por el sistema. A medida que el usuario intenta descubrirlo, el juego proporciona pistas para indicar si el número es mayor o menor.
